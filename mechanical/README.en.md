# Mechanical Design (Mechanical)

This folder contains all materials related to structural development, 3D enclosure modeling, and engineering documentation release.

## Directory Structure

* **[`drawings/`](/mechanical/drawings)** — folder with engineering drawings and specifications in the native KOMPAS-3D format (`.cdw`).
* **[`enclosure/`](/mechanical/enclosure)** — parametric 3D models of enclosure parts (`.m3d`), ready-to-print 3D printing files (`.stl`), and the 3D model of the assembled device (`.a3d`).
* **[`images/`](/mechanical/images)** — graphical assets (high-quality 3D model renders and drawing screenshots).
