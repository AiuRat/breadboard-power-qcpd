# Проектирование механической части (Mechanical)

Здесь содержатся все материалы, связанные с разработкой конструкции, 3D-моделированием корпуса и выпуском конструкторской документации.

## Структура директории

* **[`drawings/`](/mechanical/drawings)** — папка с конструкторскими чертежами и спецификациями в исходном формате КОМПАС-3D (`.cdw`).
* **[`enclosure/`](/mechanical/enclosure)** — параметрические 3D-модели деталей корпуса по частям (`.m3d`), готовые файлы для 3D-печати (`.stl`) и 3D-модель устройства в сборе (`.a3d`).
* **[`images/`](/mechanical/images)** — графические материалы (высококачественные рендеры 3D-моделей и скриншоты чертежей).
