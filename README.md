# Breadboard Power QC/PD

Модуль комбинированного питания для беспаечных макетных плат с поддержкой протоколов быстрой зарядки **USB Power Delivery (PD)** и **Quick Charge (QC)**.

  <img src="/production/images/assembled-pcb-top(pretty).jpg" width="850" alt="Breadboard Power QC/PD Assembled Board">
</p>

---

## 1. Описание проекта

**Breadboard Power QC/PD** — это компактное, универсальное устройство, призванное решить проблему питания прототипов на беспаечных макетных платах. Традиционные лабораторные блоки питания громоздки и требуют ручной настройки, а дешевые китайские модули питания макеток ограничены жесткими рамками $5\text{ В}$ и $3{,}3\text{ В}$ при малом токе.

Данный проект объединяет современные технологии быстрой зарядки по протоколу **USB Type-C (QC/PD)**, высокую точность линейных стабилизаторов и широкие возможности импульсных DC-DC преобразователей. Модуль подключается напрямую в боковые шины макетной платы и предоставляет инженеру независимые каналы питания для цифровой логики, микроконтроллеров и аналоговых микросхем (двуполярное питание $\pm 15\text{ В}$).

---

## 2. Основные технические характеристики

* **Входной интерфейс:** USB Type-C (с поддержкой PD 3.0 / QC 3.0)
* **Интерфейс подключения:** Двухрядные штыревые разъемы с шагом $2{,}54\text{ мм}$ (под стандартные шины макетных плат)
* **Доступные каналы и напряжения:**
  * Силовой регулируемый канал (`VBUS`): **$5\text{ В}$ / $9\text{ В}$ / $12\text{ В}$ / $15\text{ В}$ / $20\text{ В}$** (определяется триггером)
  * Канал питания логики (`3.3Vout`): **$+3{,}3\text{ В}$** (малошумящий линейный LDO-стабилизатор)
  * Канал отрицательного плеча (`-15out`): **$-15\text{ В}$** (импульсный инвертирующий преобразователь)

---

## 3. Схемотехника и архитектура устройства

Полная принципиальная электрическая схема модуля:

<p align="center">
  <img src="/docs/images/breadboard-power-qcpd-schematic.png" width="850" alt="Принципиальная схема Breadboard Power QC/PD">
</p>

### Архитектура модуля состоит из трех ключевых узлов:
1. **Узел триггера быстрой зарядки:** Выполнен на специализированной микросхеме **CH224K**. Она ведет переговоры с внешним источником питания (адаптером) через линии `CC1/CC2` и «вытягивает» нужное напряжение на шину `VBUS`. Конфигурация задается DIP-переключателем `SA2`.
2. **Линейный LDO-стабилизатор ($+3{,}3\text{ В}$):** Построен на базе микросхемы **LD1086DT33TR** (в корпусе TO-252) с входными и выходными фильтрующими конденсаторами емкостью $10\text{ мкФ}$.
3. **Импульсный инвертор ($-15\text{ В}$):** Выполнен по инвертирующей схеме на ШИМ-контроллере **MC34063AG-S08-R** без внешнего ключа. Частота работы генератора задается емкостью $C_1 = 2{,}2\text{ нФ}$ ($\approx 97{,}5\text{ кГц}$).

## 4. Конструкция и 3D-моделирование (Mechanical Design)

Для защиты электроники и удобства использования был спроектирован двухсоставной защитный пластиковый корпус в среде **КОМПАС-3D** (соединение деталей по системе шип-паз):

<p align="center">
  <img src="/mechanical/images/breadboard-power-qcpd-assembly(1).png" width="650" alt="3D-модель корпуса - Вид 1">
</p>

*Детали корпуса (крышка и подложка) оптимизированы под аддитивное производство методом FDM-печати на 3D-принтере (файлы `.stl` для печати находятся в папке [`mechanical/enclosure/`](/mechanical/enclosure)).*

Устройство было успешно спаяно и прошло тестирование:

В ходе верификации с помощью цифрового осциллографа была подтверждена стабильность работы встроенного генератора инвертора и непрерывный режим работы силовой индуктивности:

<p align="center">

* **Осциллограмма C1 (слева):** Подтверждает рабочую частоту переключения преобразователя $97{,}5\text{ кГц}$ (в пределах допустимой нормы в $100\text{ кГц}$).
* **Осциллограмма L1 (справа):** Подтверждает правильный выбор индуктивности $220\text{ мкГн}$, обеспечивающий стабильный непрерывный ток дросселя без ухода в режим разрывных токов.

## 7. Навигация по проекту

Репозиторий имеет четкую модульную структуру. Перейдите в интересующий вас раздел по ссылкам ниже для ознакомления с исходными материалами:

* 📁 **[`/electronics`](/electronics)** — Аппаратная часть проекта. Содержит исходные файлы схемы и платы в формате EasyEDA, а также подпапку **[`verification`](/electronics/verification)** с подробными математическими расчетами обвязки преобразователя и осциллограммами тестов.
* 📁 **[`/mechanical`](/mechanical)** — Механическая часть и корпус. Содержит исходные параметрические модели деталей корпуса в КОМПАС-3D (`.m3d`, `.a3d`) и готовые файлы для 3D-печати на FDM-принтере (`.stl`).
* 📁 **[`/production`](/production)** — Файлы для самостоятельной сборки и заказа. Содержит архив Gerber-файлов для завода (`gerber.zip`), перечень элементов для закупки компонентов (`BOM.xlsx`) и чертежи в формате PDF.
* 📁 **[`/docs`](/docs)** — Техническая документация. Содержит глубокое описание физики работы схемы устройства, таблицы истинности переключателей и подпапку **[`datasheets`](/docs/datasheets)** с оригинальной документацией на используемые микросхемы.
