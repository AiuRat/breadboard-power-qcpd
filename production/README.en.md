# Manufacturing Files (Production)

This folder contains all materials necessary for self-fabrication of the printed circuit board, component sourcing, and assembly of the finished device.

## Directory Contents

* **[`gerber.zip`](/production/gerber.zip)** — ready-to-use archive with Gerber files and drill map. Fully ready to be uploaded to manufacturers' websites (JLCPCB, PCBWay, etc.).
* **[`breadboard-power-qcpd-bom.xlsx`](/production/breadboard-power-qcpd-bom.xlsx)** — Bill of Materials (BOM) with component specifications. 
  *(Note: the spreadsheet contains direct purchase links for electronics parts from the "Chip and Dip" store, though some links may become outdated over time).*
* **[`drawings/`](/production/drawings)** — complete set of engineering and design documentation (drawings, specifications) in **`.pdf`** format.
