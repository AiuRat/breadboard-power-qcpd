# Файлы для производства (Production)

Здесь содержатся все материалы, необходимые для самостоятельного изготовления печатной платы, закупки компонентов и сборки готового устройства.

## Содержимое директории

* **[`gerber.zip`](/production/gerber.zip)** — готовый архив с Gerber-файлами и картой сверловки. Полностью готов для загрузки на сайты изготовителей (JLCPCB, PCBWay и др.).
* **[`breadboard-power-qcpd-bom.xlsx`](/production/breadboard-power-qcpd-bom.xlsx)** — перечень элементов (Bill of Materials) со спецификациями компонентов. 
  *(Примечание: в таблице приведены прямые ссылки на покупку радиодеталей в магазине «Чип и Дип», однако со временем некоторые ссылки могут устаревать).*
* **[`drawings/`](/production/drawings)** — полный комплект конструкторской документации (чертежи, спецификации) в формате **`.pdf`**.
