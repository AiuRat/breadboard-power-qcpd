# Hardware Development (Electronics)

This folder contains all materials related to the design, calculation, and routing of the combined power module PCB.

## Directory Structure

* **[`easyeda`](/electronics/easyeda)** — source project files in `.json` format for import into EasyEDA CAD (schematic and PCB topology).
* **[`verification`](/electronics/verification)** — folder with detailed engineering calculations for component values, formulas, and waveforms from physical testing of the finished prototype.
* **[`images`](/electronics/images)** — graphical assets of the project (screenshots of the schematic, routing layers, and 3D PCB models).
